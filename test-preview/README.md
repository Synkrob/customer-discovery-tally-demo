# Customer Discovery Tally — Hosted test preview

This path is a clearly labeled, sample-only hosted test preview of the newer Quick Demo Creator. The older public demo remains at the repository root.

Included demo profiles:

- SMASH Dance Studios
- Alkaline Water Leon Valley
- Alkaline Water Austin Highway
- Neighborhood Coffee Co. (fictional)

The editor previews business name, industry, accent, optional local logo, and an optional local photo background. Photo previews stay in browser memory only; they are not uploaded, persisted, or embedded in URLs. The native picker may offer a camera option on supported devices but never opens it automatically. The app has simulated roles and fictional sample data only—no authentication, backend, payments, customer records, or production access control.
